# BUG-041: workers must remain paused at zero duty

Status: **FIXED, deployed and verified on all six nodes, 2026-09-30.**

Both mining callbacks now use an interruptible wait for positive duty. Each
bounded throttle sleep is followed by shutdown and job-generation checks.
Workers also check before reserving a search range. A paused search retains
its position; a changed tip or science anchor invalidates the old job without
consuming ranges on its replacement while duty is zero. No consensus rules,
thermal thresholds or wallet formats changed.

## Verification

- Actual two-worker regression: initial zero duty, running-to-paused transition,
  stable search-range cursors and counters, resume in both lanes, changed tip
  and science anchor while paused, and prompt shutdown. The original worker
  code fails this regression; the fix passes.
- Host, native x86 image and native ARM image: **732/732** top-level C checks,
  thermal simulation, three snapshot tests and Python cross-checks passed.
- Isolated Compose sampler tests: battery offline, stale sensor and synthetic
  over-temperature input each produce two consecutive status intervals with
  **zero candidates/second and unchanged science/share counters**. Both lanes
  resume; all three daemons exit cleanly while paused. Synthetic inputs are
  confined to this lab, never installed on a live miner.
- Live mini canary: suspended its real macmon publisher with a remote resume
  watchdog. After the in-flight work/measurement interval drained, two status
  samples reported zero candidates/second, science count **9088022** and share
  count **3363**, unchanged. Peer synchronization continued from heights
  **43890 to 43900**, with zero pending orphans. Restoring the real publisher
  resumed both lanes at height **43909**.

Evidence: [sampler integration](evidence/2026-09-30-bug041-sampler.json),
[live ARM canary](evidence/2026-09-30-bug041-canary.json).
`check_pause.py` reproduces the isolated sampler experiment using a new private
output directory. The first status interval after a pause can include work
done before the pause; the checks use subsequent complete intervals.
